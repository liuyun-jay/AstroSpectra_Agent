# AstroSpectra_Agent
A Multi-Agent Framework for Planetary Mineral Spectroscopy and AI-driven Migration Research
# 🚀 AstroSpectra-Agent: 地-星光谱跨域分析多智能体系统

本项目旨在通过大语言模型（LLM）与多智能体（Multi-Agent）协同，加速地质工程（地球矿物）向行星科学（火星/月球深空探测）的光谱数据分析与迁移研究。诚邀相关领域专家指导。

## 🎯 核心痛点

传统行星矿物学研究受限于“数据孤岛”与“知识断层”。研究者在分析光谱数据时，需手动从海量英文顶刊中提取数千个矿物的特征吸收峰，并针对不同传感器的噪声编写繁杂的预处理算法。这一过程耗时极长，严重制约了科研效率。

## 🧠 核心逻辑流与架构

本项目构建了一个高度依赖大模型**长上下文**与**代码推理**能力的自动化科研工作流。包含三大 Agent 协同：

- **文献挖掘 Agent (Geology Reader)**：利用 RAG 与超长上下文能力，一次性吞吐并解析数十篇行星科学英文顶刊 PDF，提取 SWIR 关键吸收特征。单次完整分析需消耗约数十万 Token。
- **算法生成 Agent (ML Coder)**：基于先验知识，自动编写并迭代 PyTorch/Scikit-learn 光谱分析代码。内置代码沙箱“执行-报错-修正”的闭环，高频调用带来海量 Token 消耗。
- **星际迁移 Agent (Planetary Mapper)**：将斑岩矿物的特征提取逻辑，跨域映射至行星科学视角（如对标中科院地质地球所深空探测方向），并自动生成学术级英文对比报告。

## 📊 量化成果与应用场景

- 目前该系统原型已赋能本人主持的“**机器学习在斑岩矿床SWIR光谱数据分析中的应用**”大创项目。
- 传统人工耗时数天的文献特征提取与基准代码搭建，现缩短至 **15 分钟**内闭环。
- 系统日常运行涉及高频、长文本的文献检索与代码自我演化，每日稳定具备**数百万级 Token** 的高强度吞吐需求。
